# Subhajit Show Portfolio

## Run
Open `index.html` with VS Code Live Server.

## Add your real links
Replace the `#` links in `index.html` with your GitHub, LinkedIn, Instagram and project URLs.

## Add Udemy certificate
Put your certificate image at:
`assets/images/udemy-certificate.png`

Then replace the certificate placeholder in `index.html` with an `<img>` if desired.

## Contact
The contact form is currently frontend-only. Connect it to an Express/Node backend or an email service later.
